# Product Management App

A simple product management application with shopping cart functionality.

## Install and run

```bash
npm install
npm run dev
```

Then open http://localhost:5173 in your browser.

## Features

- Product listing with category filter
- Product detail page
- Add new products with form validation
- Shopping cart with quantity controls and subtotals
- Overall total of all products
- Clear cart button
- Low stock highlighting
- Responsive mobile layout

## Tools

- React
- Vite
- React Router
